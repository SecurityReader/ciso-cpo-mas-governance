# R41 부분 재실행 — 출력 상한(truncation) 강건성 표본 검증

## 목적
정본 실험은 전 답변(108/108)이 `MAX_TOKENS`(2000/4000) 상한에 도달해 출력이 절단됐다(검토 지적 R41).
채점 대상이 **최종정책(final)** 이므로 절단이 점수에 영향을 줄 수 있다.
여기서는 상한을 **8000으로 통일**해 소수 시나리오만 재생성·재채점하고,
정본(4000-절단본)과 **같은 (시나리오,조건)** 에서 점수·길이를 비교한다.
→ 전체 재실행(약 8~9.5M 토큰) 없이 "상한 완화가 결론을 바꾸지 않는다"를 표본으로 입증.

## 안전장치
- 정본 `output/traces`·`output/eval` 은 **건드리지 않는다.** 모든 산출물은 `r41_recheck/` 안에만 기록.
- 대상: 고난도(가장 길고 잘리기 쉬운) 4개 — CFL-01, CFL-05, CFL-06, CFL-08 × 3조건 × 1반복 = **12답변**.
- `_dry_test/` 폴더는 스크립트 동작 검증(dry, 무과금) 잔재다. 삭제해도 무방(내용 무의미).

## 실행 순서 (r41_recheck 폴더에서)
```bash
# 0) 키: 상위 harness 와 동일한 .env(또는 환경변수)로 API 키 준비
#    (LLM_BACKEND=api 기본. 사내 프록시면 상위 harness 와 동일하게 CA 설정)

python run_gen.py     # 생성: 12답변, MAX_TOKENS=8000, REPS=1   (약 0.6~0.8M 토큰)
python run_judge.py   # 채점: 12×3심판 = 36콜                  (약 0.1~0.2M 토큰)
python compare.py     # 비교표 출력 (무과금)
```
합계 약 **0.8~1.0M 토큰** (전체 재실행의 약 1/10).

## 결과 해석 (compare.py)
각 (시나리오,조건)마다: 최종정책 길이(old→new), 복합점수 S(old→new), ΔS, 바뀐 지표.
- 하단 **판정**: 최대 |ΔS| < 1.0 (SESOI) 이면
  → "상한 완화가 채점을 실질적으로 바꾸지 않음 = 절단은 결론에 영향 없음" 근거 확보.
- 길이는 늘되(new_len↑) 점수 S가 거의 그대로면, 잘린 부분이 **채점 항목에 중요하지 않았다**는 뜻.

## 다음

동등성 결론 불변")을 원고에 작성한다.
